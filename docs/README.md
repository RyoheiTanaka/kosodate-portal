# docs

このプロジェクトの設計判断や調査結果を残す場所。

## 置き場所の使い分け

| 場所 | 用途 | 公開 |
| --- | --- | --- |
| `docs/` | 設計判断、調査結果、運用手順。後から読み返す価値があるもの | される |
| `docs/local/` | 下書き、作業ログ、まだ人に見せる形になっていないメモ | されない（gitignore） |

`docs/local/` は `.gitignore` に入れてあるので、体裁を気にせず書ける。
まとまったら `docs/` に移す。

## 公開リポジトリなので入れてはいけないもの

- 接続文字列・APIキー・パスワードなどの秘密情報（`.env` に置く。`.gitignore` 済み）
- 個人に紐づく情報（担当者の携帯番号、氏名など）
- 他人の著作物

逆に、試行錯誤の経緯や失敗の記録は入れてよい。むしろ残す価値がある。
